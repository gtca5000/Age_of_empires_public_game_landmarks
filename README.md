# Age of Empires Public Game Landmarks

Cozy painterly real-time strategy game sprites in Age of Empires II mixed with warm hand-painted storybook style.

Generated isolated landmarks and assets for Adelaide and related Mediterranean-inspired elements.

## Assets
- Mall's Balls
- Adelaide Oval
- Paved cobblestone road
- Adelaide Zoo entrance (with koala)
- Torrens footbridge
- Victorian band rotunda
- Adelaide Central Market in Bloom

## How to get the sprites (for Claude Code)
A single zip of all sprites will be available as `adelaide_landmarks_sprites.zip.b64`.

After cloning:
```bash
base64 -d adelaide_landmarks_sprites.zip.b64 > adelaide_landmarks_sprites.zip
unzip adelaide_landmarks_sprites.zip
```

The zip contains the seven PNG/JPG sprites with clean names.
